🎬 ThuVienCine Kodi Repository

Kho cài đặt chính thức của addon ThuVienCine dành cho Kodi

⚠️ Lưu ý: Chỉ cài đặt addon từ các nguồn đáng tin cậy. Các repository không rõ nguồn gốc có thể chứa mã độc hoặc gây mất an toàn cho tài khoản của bạn.

📺 Video hướng dẫn cài đặt

🎥 Xem video hướng dẫn trên YouTube

📖 Hướng dẫn đầy đủ cách cài Kodi

📋 Hướng dẫn cài đặt

  1. Mở Kodi → Settings → File Manager
  2. Chọn Add source và nhập: https://thuviencine.github.io/
  3. Đặt tên nguồn: thuviencine
  4. Vào Add-ons → Install from zip file
  5. Chọn nguồn thuviencine
  6. Chọn repo_thuviencine-0.0.1.zip
  7. Sau khi cài repository thành công: Install from repository → THUVIENCINE → Video add-ons → ThuVienCine
  8. Addon sẽ tự động cập nhật khi có phiên bản mới 🎉
💡 Mẹo: Nếu cài từ repository không thành công, bạn có thể cài trực tiếp từ file ZIP của addon trong thư mục nguồn.
